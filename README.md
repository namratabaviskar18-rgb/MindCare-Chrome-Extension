# 🧠 MindCare 2.0

### Mental Health Awareness & Self-Reflection Chrome Extension

MindCare 2.0 is a privacy-friendly Chrome extension designed to encourage mental health awareness, daily self-reflection, mood tracking, journaling, and healthy coping habits.

The extension provides a simple and private space where users can record their mood, write personal journal notes, reflect on their recent wellbeing, and access supportive resources.

---

## ✨ Features

- 😊 Daily Mood Tracker
- 📊 Personal Dashboard
- 🔥 Mood Tracking Streak
- 📔 Private Journal
- 🌙 Dark Mode
- 🧠 Self-Reflection Questionnaire
- 💭 Daily Positive Thoughts
- 🌱 Wellness & Care Tips
- 📞 Mental Health Support Resources
- 🔒 Local data storage using Chrome Storage
- 🚫 No login required
- 🚫 No external database
- 🚫 No analytics or tracking

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chrome Extension Manifest V3
- Chrome Storage API
